# market-signals: портфельний монітор

Щоденний звіт за механічною стратегією з [`docs/strategy.md`](docs/strategy.md): портфель із чотирьох блоків
(ядро довгих Treasuries, світові акції, CTA-хедж, кеш). Звіт показує **режим, цільову модельну алокацію
й угоди цього тижня**, а бектест на тому самому коді перевіряє пороги на історії з 2008 року.

| Блок | Сигнальний ряд | Виконання | Діапазон |
|---|---|---|---|
| Ядро — довгі Treasuries | TLT | USD 20+ (TLT/VGLT — legacy) | 30–70% |
| Акції — весь світ | ISAC.L | ISAC.L | 15–25% |
| CTA-хедж | DBMF | DBMF.PA | 5–25% |
| Кеш | IB01.L | IB01 / VDST | решта, мін. 10% |

## Як це працює

```
GitHub Actions (cron, Пн–Пт 22:30 UTC)
  └─ signals.py: FRED + yfinance → треки по днях (inputs.py)
       → рушій правил (engine.py) від portfolio.yaml до сьогодні
       → data/signals.json, data/history.csv
       ├─ змінився режим / сходинка / ціль / з'явились угоди → Telegram

```
Уся математика детермінована й живе в коді. Claude лише пояснює готові числа.

### Треки (векторно, DataFrame по днях)
| Трек | Джерела | Що рахує |
|---|---|---|
| **core** | Yahoo TLT | TLT vs SMA200, SMA50 vs SMA200, відстань у %, днів поспіль вище SMA200, RSI-дивергенція |
| **rates** | FRED DGS2/10/30 | Зміна 10Y за 20 днів, реалізована вол. 10Y і її перцентиль за рік, перцентиль 30Y за 5 років, нахили кривої |
| **stress** | FRED DGS10, IG OAS (бектест: BAA10Y), VIX | Три умови Стресу (§2) окремими прапорцями + загальний `stress`; HY OAS і NFCI — контекст |
| **cta** | Yahoo DBMF, TLT, FRED DGS10 | Скоринг 0–10 з 5 компонентів (§5), DBMF vs SMA100, 20-денні дохідності, 60-денна кореляція, правило зрізання, розбіжність DBMF.PA vs DBMF |
| **equity** | Yahoo ISAC.L | ISAC vs SMA200, днів поспіль вище |
| **macro** | FRED CPI, NFP, UNRATE | Лише контекст для брифу |

### Рушій правил (`engine.py`)
`step(state, day, cfg) -> (state, actions)` — чиста функція без файлу стану й без `today()`.
Порядок у межах дня: дрейф ваг з дохідностями → режим (кандидат + 5 днів підтвердження;
Стрес > Ставки ростуть > Базовий) → ядро (сходинки −7/−14/−20% від піку циклу, пауза «схоже на дно»,
повернення по 10 п.п. не частіше ніж раз на 2 тижні, скидання піку) → CTA (ціль зі скорингу, вгору
траншами по 5 п.п., вниз одразу, зрізання) → акції (база 15% завжди, розширення до 25% траншами, вихід
додаткових, річний ребаланс бази) → кеш ≥ 10% → виконання (день виконання — останній торговий день тижня;
у Стресі сходинки ядра й вихід із додаткових акцій — одразу; зміни < 2 п.п. ігноруються).

Кожна угода — `Action(date, block, from_weight, to_weight, reason)` з причиною людською мовою.

Трактування, узгоджені під час впровадження:
- сходинки спрацьовують лише в режимах «Ставки ростуть» і «Стрес»; у Базовому ядро тримається на цілі;
  у Стресі — лише якщо TLT нижче SMA200 (захист від хибних продажів у висхідному тренді облігацій);
- «тренд вниз» для −20% = TLT нижче SMA200 і SMA50 нижче SMA200;
- «висока волатильність ставок» у Стресі = перцентиль реалізованої вол. 10Y ≥ 80;
- дрейф ядра/CTA/акцій далі ніж на 5 п.п. від цілі → ребаланс (докупівля ядра — лише в Базовому режимі).

## `portfolio.yaml`
Стартовий стан, який ви редагуєте вручну після угод:
```yaml
as_of: 2026-10-01
weights: {core: 70, cash: 30, cta: 0, equity: 0}
core_peak: auto   # максимум TLT за 252 дні до as_of; або число
```
Живий звіт проганяє рушій від `as_of` до сьогодні. Перехід від стартового стану (§7): скорочення ядра
й мінімальні 5% CTA — одразу, нарощення ризику (акції до 15%, CTA понад 5%) — по 5 п.п. на тиждень.
Після виконання угод оновіть `as_of` і `weights` — рушій стартує з нового стану.

## Виходи
- `data/signals.json` — `regime` (+ кандидат і лічильник), `portfolio` (ваги до угод тижня),
  `model_weights` (після), `target`, `actions_this_week` (з `when` і `reason`), `core` (пік, просадка,
  сходинка, пауза, ознаки дна), `cta_score` з розкладом, `tracks`, `warnings`, `alert_log`.
- `data/history.csv` — дата, режим, модельні ваги, просадка ядра, скоринг CTA, 10Y, IG OAS, VIX.
- `data/backtest/` — `equity_curve.csv`, `actions.csv`, `summary.md`.

## Бектест
```bash
FRED_API_KEY=... python backtest.py            # комісія 0,1% від обороту
FRED_API_KEY=... python backtest.py --fee 0.002
python backtest.py --demo                      # синтетичні дані
```
Прогони з 2008 (CTA: RYMFX → AQMIX → DBMF) і з 2010 (AQMIX → DBMF); акції ACWI → ISAC.L,
кеш DTB3 → IB01.L, умова Стресу по кредиту — BAA10Y (ICE OAS на FRED є лише за ~3 роки).
Порівняння з 60/15/25 з річним ребалансом і 100% TLT, підперіоди 2013/2020/2022/2023,
чутливість до порогів сходинок (±2 п.п.) і днів підтвердження режиму (3/5/10).
У CI бектест не запускається.

## Налаштування
1. **FRED API key** — безкоштовно: https://fred.stlouisfed.org/docs/api/api_key.html
2. **Telegram-бот**: `@BotFather` → `/newbot` → токен; напишіть боту, відкрийте
   `https://api.telegram.org/bot<TOKEN>/getUpdates` і візьміть `message.chat.id`.
3. **Secrets** (Settings → Secrets and variables → Actions): `FRED_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
4. Actions → `signals` → **Run workflow**.

## Структура коду
```
signals.py      — живий звіт: дані → треки → рушій → JSON/CSV/Telegram
backtest.py     — бектест на тому самому рушії
engine.py       — рушій правил: StrategyConfig, EngineState, DayInputs, Action, step(), run(), preview()
inputs.py       — збирає треки в один DataFrame по днях (календар NYSE)
sources.py      — FRED, yfinance, chain_returns (склейка за дохідністю), align, demo_data
indicators.py   — чисті функції (RSI, дивергенція, перцентилі, z-score, streak)
tracks/         — core, rates, stress, cta, equity, macro
tests/          — pytest: правила рушія, векторні треки, склейка рядів
portfolio.yaml  — стартовий стан портфеля
config.yaml     — тікери, проксі, серії FRED, вікна індикаторів, пороги стратегії
```

## Застереження
- Акції — `ISAC.L` (LSE, USD). `SSAC.L` — той самий фонд у GBp: його ряд містить курс GBP/USD, тому не підходить.
- Ціни скориговані (з дивідендами). Різні біржі (NYSE/LSE/Paris) вирівнюються на календар NYSE з `ffill(limit=5)`.
- У перші дні лістингу Yahoo має глюки цін (IB01.L 2019-02-22): стики проксі зсунуто,
  а денні рухи > 50% у рядах ETF обнуляються; у живому звіті такий стрибок дає попередження.
- DBMF.PA на Yahoo є лише з 2025-03 — використовується тільки для моніторингу розбіжності з DBMF.
- Це інструмент моніторингу правил, а не інвестиційна порада.
